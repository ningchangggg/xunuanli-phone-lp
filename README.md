## 原始檔（_原始檔/）
- `assets.py`：Widget、受眾卡照片、尺寸畫面、作家照、兌換截圖 → img/
- `clips.py`：動圖片段（V1b、V5b／V4b／V3b 綠幕重合成、尺寸切換、拆解、兌換）→ 暫存 work/gif/clips
- `build_page.py` → page.html；`shot.py` 靜態截圖；`render_gif.py` 逐格截圖；`enc.sh <區塊> <格率>` 轉 GIF＋MP4（s06a 用 18，其他片段 15，s06／s08／s03b 用 10）；`deliver.py` 整理交付
- 重做：`python3 -E -P assets.py && python3 -E -P clips.py && python3 build_page.py && python3 shot.py && python3 render_gif.py`，再跑 enc.sh、deliver.py（暫存資料夾路徑寫在 build_page.py 的 WORK，被清掉的話重跑 clips.py）
